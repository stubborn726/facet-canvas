# 使用手册

> 面向使用者：怎么起服务、怎么改、怎么导出。**第一次跑**先看 [README](../README.md) 的「快速开始」。

```bash
cd facet-canvas
node server.js                 # → http://localhost:3000
TRUST_PROXY=1 node server.js   # 反代/公网部署：让限流看到真实客户端 IP
ADMIN_PASSWORD=新口令 node server.js   # 忘记管理员密码时重置（一次性，之后正常启动）
# 或者用 npm（等价，package.json 已内置脚本，无需 npm install）
npm start                      # = node server.js
npm run dev                    # = node --watch server.js（改后端自动重启）
```

> **不需要 `npm install`、不需要构建**——零依赖、无编译步骤；前端就是 `index.html` + `app.js` + `style.css` 三个原生文件（浏览器直接跑，连打包器都不需要）。
> 这就是为什么不像其他项目那样必须先 `npm run dev`：那些项目要用 Vite/webpack 把 TS/JSX/Vue 编译打包并热更新，我们没有可编译的东西。
> 代价是**没有热更新**：改前端刷新浏览器即可；改 `server.js` 需重启（或用 `npm run dev` 自动重启）。

- 需 **Node 22.5+**（用内置 `node:sqlite`）。**22.x 要加 `--experimental-sqlite`**，24+ 直接跑。版本不够会报错退出并提示。
- 自测：`npm test`（起临时实例跑一遍登录/保存/版本/恢复/体检，不碰你的 `data/`）。
- **首次启动自动建管理员** `admin` / 初始口令（见 [auth.md](auth.md)；写在源码里，所以是"入场券"）→ 登录后**强制改密**才放行。
- 可选：`PORT=8080`、`TOKEN_DAYS=365`（令牌有效期，默认 365 天）、`DB_PATH=...`。
- **账号在右上角「操作人」里管**：改自己的密码；管理员另有「用户管理」（新增/改角色/重置密码/删除）。
- 可选：`IP2REGION_XDB=路径` 指定归属地数据文件（默认读 `vendor/ip2region_v4.xdb`，也认老名字 `ip2region.xdb`）。
- **首次运行**（`meta.seeded` 未置位时）自动用 `seed.json` 播种并生成"初始版本"。
  **用户把画布清空并保存后，重启不会再复活种子**（旧行为会，属缺陷）。
- 数据：全部运行时数据都在 **`data/`** 一个目录里 —— `data.db`（SQLite，结构化数据）+ `uploads/`（流程图图片文件）。**备份只要备 `data/` 这一个目录**；用自带的 `node backup.js` 即可（一致性快照 + 拷图 + 保留最近 14 份，可在服务运行中执行）。
- **单实例**：SQLite 单文件库，**不要**起多个进程指向同一个 `data.db`（会锁冲突/写坏）；要扛并发得换 Postgres。
- **动数据前后想留证据**：`node verify.js`（体检 + 指纹）、`node verify.js --save ../升级前.json` → 改完 `node verify.js --baseline 升级前.json`（详见下节「数据体检」）。

> 完整步骤（systemd / pm2 / Windows 服务 / nginx / 备份迁移）见 **[`DEPLOY.md`](../DEPLOY.md)**。

1. 拷整个目录到服务器。
2. `node server.js`（常驻可用 `pm2` / systemd；需要时 nginx 反代）。
3. 访问 `http://<服务器IP>:3000` → 用 `admin` + 初始密码登录 → 按提示改密 → 在「用户管理」里给同事建账号。

> 无构建、无 `npm install` 即可跑。

## 顶栏的访问信息（IP / 归属地）

右上角显示 **当前访问的 IP**，有归属地库时再显示 **省 市**，只读登录会多一个「只读」标签。

- IP 取自 TCP 连接；反代后要 `TRUST_PROXY=1` 才拿得到真实客户端 IP（否则是代理的 IP）。
- 归属地是**离线**查表：把 ip2region 的 `ip2region_v4.xdb`（约 11MB，官方现已改名，旧的 `ip2region.xdb` 链接已 404）放到 `vendor/`，重启即生效。**不放也能用**——只是这一行少一截，其余一切不变。

  ```bash
  node lib/geo.js 114.114.114.114      # 自测：能打印出解析结果 = 数据文件正确
  ```

- **它是"出口 IP 的大致位置"，不是人的位置**：内网地址（`10./192.168./172.16-31.` 等）显示「内网」；同一办公网 NAT 之后大家是同一个 IP；宽带/移动常定位到运营商节点城市。别拿它当身份或考勤依据。

## 编辑与版本（草稿模型）

- **编辑 = 草稿**：增删节点、改名、标注、分组、连线、挂流程图，**都只改浏览器里的草稿**，服务器不变。
- **保存**：点「**保存**」或按 **Ctrl+S** → **不再弹窗、不填版本说明**，直接提交并**生成一个新版本**；成功后只在顶部闪一条**低调的轻提示**（自动消失）。此后刷新/他人可见。
- **撤销 / 重做**：**Ctrl+Z** 撤销、**Ctrl+Y**（或 `Ctrl+Shift+Z`）重做，覆盖所有草稿期改动；**会话内、内存**（刷新即清空，不进库）。
- **未保存标记**：有草稿时顶部显示 `● 有未保存的改动`，且**暂停自动刷新**（免得冲掉你的草稿）；关闭页面会提醒。
- **草稿兜底**：草稿同时存 `localStorage`；若刷新/崩溃，重新打开会在**恢复草稿 / 丢弃草稿 / 稍后再说**之间选择。恢复时**以草稿自己的基线 `rev` 继续**，保存时若服务器已更新会正常触发冲突提示（不会被静默覆盖）。
- **冲突处理**（乐观锁）：保存时若别人已保存过 → 弹窗提示，可选「放弃我的改动并刷新」或「仍然强制覆盖」。
- **版本历史**：点「版本历史」看全部版本（时间/谁/说明/节点数）→ 可**查看**或**恢复**。
  - **时间按你本机时区显示**（库里存的是 UTC，展示时换算成本地时间——所以不会再出现"比北京时间少 8 小时"）。
- **恢复 = 生成新版本**（内容等于旧版），**历史永不销毁**。
  - **注意**：恢复回滚的是**结构**（节点 / 连线 / 栏目及其顺序），而 `备注` / `标签` / 连线 `待确认` 这类**标注按「保留当前值」处理**——旧版本快照里本来就没有这些字段，不会被清空。
    代价：**没法把标注回滚成旧样子**；且**被删过又重新恢复的节点**，其标注找不回来（库里已经没有它了）。要清空标注只能手动改。
    （设计理由：整图重写采用「**字段缺失→保留库中现值，传空串才清空**」，这样旧页面 / 旧版本快照 / 旧 localStorage 草稿都**不可能**把新信息抹掉——详见「数据模型」小节。）

## 画布浏览（缩放 / 平移）

- **缩放**：**Ctrl/⌘ + 滚轮**缩放（以光标位置为中心）；工具栏 `－` / `＋` 按钮按视口中心缩放；中间**百分比**按钮点一下**回到 100%**（范围 25% ~ 250%）。**普通滚轮不缩放**（避免误触）。
- **平移**：**普通滚轮**上下/左右平移画布，或按住**空格 + 鼠标左键拖动**（或按住**滚轮中键**拖动）；按住空格时鼠标变成抓手，节点不可拖拽，避免误操作。平移有**边界约束**（至少留 48px 内容可见，不会把画布拖丢）。
- **自适应**：点工具栏「**自适应**」→ **回到刚打开的视图**（**100% 缩放 + 顶部/左侧对齐**）——平移/缩放乱了，点一下回正。内容比视口高时用**滚轮 / 空格拖动**平移查看。（**不再自动缩小**：自动缩会把字变小、并牵动列宽导致连线错位。）
- **锁定画布**：点工具栏「**锁定画布**」→ 画布进入**只读**：冻结**滚轮缩放/平移、空格平移、拖动节点/栏目、框选**，且**编辑入口一律停用**（节点/连线**右键菜单不弹**、编辑类快捷键、`＋栏目`），一律提示"先解锁"——防止"看的时候手一抖"把画布弄乱。**点选、高亮、顶部缩放按钮、自适应**仍可用。再点一次解锁；**刷新后回到未锁定**（不持久化）。
- **打开页面默认 100%、左上对齐**（观感同原来的弹性布局；不会自动缩放/居中）。
- 画布为**固定视口**（不再整页上下滚动）：内容超出视口时用缩放 / 平移查看。
- 缩放只做整体 `transform`，**连线随之一起缩放、无需重算**；框选、连线、拖拽等编辑操作在缩放状态下同样可用（内部已按缩放比例换算坐标）。
- 常驻区只留**一行提示**（动态提示 + 「**? 使用说明**」按钮）；完整的图例 / 快捷键 / 约束说明都在那个弹层里——为的是把纵向空间让给画布。
- **连线密集时怎么看清**（`团队 × 交付物` 这种多对多最容易糊成一片）：
  - **默认线很淡**（1px、约 50% 不透明），密集处叠成"薄雾"而不是一块橙色；待确认的橙色虚线保持更实，仍能一眼找到。
  - **同一栏间通道里按起端节点错开"腰"**：不同部门出来的线不再挤在同一条竖直中线上，而是一束可分辨的线（错位只挪控制点，端点始终连在节点上，也不会越出通道）。
  - **鼠标停在一条线上、或停在某个节点上 → 其余线淡出**，顺着一条看；移开即恢复。（停在线上的命中区在**查看模式**也有，方便浏览。）
  - 想立刻减少线量：把顶部「**显示待确认**」关掉（或点节点用链路高亮聚焦一条链）。

## 多画布

顶栏蓝色区域有「**画布：<名字> ▾**」，点它弹出（和右键菜单同款）浮层：

```
✓ 示例画布                 ← 当前画布（打勾）
  交付链路
  ──────────────
  ＋ 新建画布…
  ⧉ 复制当前画布…
  ✎ 重命名当前画布…
  ✕ 删除当前画布…（二次确认）
```

- **每张画布各自一套栏目、节点、连线、版本历史**——换个分析角度就新建一张画布，互不干扰。
- **新建**只填名字：得到一张**空白画布 + 默认 4 栏**（团队 / 能力 / 交付物 / 外部依赖）。
- **复制**：以**当前画布**为模板另存一张（默认名 `「原名 副本」`）——**栏目 / 节点（含备注、标签、分组、图片、排序）/ 连线全带过去，逐行一致**；**版本历史不复制**（新画布只有 1 个「复制自「源名」」的初始版本，可作还原点）；流程图**图片共享**同一个文件（不深拷）；`rev` 从 0 起。当前画布有**未保存改动**时先问「先保存 / 放弃改动 / 取消」——复制的是**已保存**的内容。
- **删除**是**两次确认**（第二次列出该画布的节点/连线/版本数），**连它的版本历史一起删**，不可恢复；但**绝不会删最后一张画布**。
- **切换**：有未保存改动时会先问「先保存再切走 / 放弃改动并切走 / 取消」，**不会静默丢草稿**；切走后清空选中并重置撤销栈。
- **草稿按画布隔离**（`localStorage` 键带画布 id）；重开页面会回到**上次所在的那张画布**。
- **乐观锁按画布**：在 B 画布保存**不会**让 A 画布后续保存报假冲突。
- 导出链路表 / 版本历史 / 重置，都只作用于**当前画布**。
- **画布锁定**时：切换画布可用，但**新建 / 重命名 / 删除**会提示先解锁。

## 编辑操作

**工具栏只留常用的**：`编辑模式` · `＋栏目` · `锁定画布` · `🔗 连线 ▾` · `🏷 标签 ▾` · `⚙ 设置 ▾`（标签类型 / 样式） · `保存` · `导出 ▾`（图片 PNG / 链路表 CSV） · `版本历史` · `显示待确认` · `显示备注` · `刷新` · 缩放组。**节点级操作一律走右键菜单**（编辑模式下，在节点上点右键）：

| 右键菜单项 | 快捷键 | 说明 |
|---|---|---|
| 改名 | `Enter` | 就地改名（见下） |
| 备注 / 标签 | — | 弹小编辑框：多行**备注** + **按类型分的多行标签框**（每个类型一个，末位是「未分类」；多个用逗号分隔）。标签框**随内容长高**（最高 190px 后内部滚动，标签再多也能看全），框下还有一行「**已有：**」候选胶囊——**点一下加入、再点一下移出**（替代原先单行框的浏览器联想，多值也一眼看全）；标签框里 **Enter = 直接确定**（`Shift+Enter` 换行） |
| 标记待确认 / 标记明确 | `T` | 切换节点置信度 |
| 从此节点连线 / 结束连线 | — | 进入/退出连线模式 |
| 上传流程图 / 流程图 | — | 同节点上的 📎 按钮 |
| 设为分组 / 取消分组 | — | 把选中的**同栏**节点圈成一个虚线框 |
| 删除节点 | `Delete` | **一次确认**（列出节点数与相连线数） |

**连线右键菜单**：标记待确认 / 标记明确、删除连线。

- **行内改名（不弹窗）**：
  - **节点**：点选节点后按 **`Enter`**（或右键 →「改名」）→ 名字变成输入框；`Enter`/点别处 = 提交，`Esc` = 取消；
  - **栏目**：**单击栏目头**（编辑模式）→ 选中该栏目（橙色描边）→ 按 **`Enter`** 就地改名，按 **`Delete`** 删除此栏目（带一次确认），`Esc` 取消选中；**双击栏目标题**也可直接改名；
  - 空名不提交；**同栏同名**（忽略大小写与首尾空格）会被拦下并提示，**不弹窗**。
  - **点编辑器以外的任何地方**（空白处、别的节点、工具栏…）= **提交并收掉**编辑器（不依赖浏览器 blur，点空白也一定生效）；要**放弃**改动就按 `Esc`。
  - > 节点**不用双击**改名：双击会与「单击选中/再点取消」和「连线模式点目标=连/再点=取消」冲突。
- **栏目头与节点配色（2026-10-21）**：栏目头默认**湖蓝 #0E8FB8**，可**按画布自定义** —— 「**⚙ 设置 ▾ → 样式**」里的「栏目头 · 底色」（20 色预设 + 系统取色器），**每张画布各存一套**（`canvases.color`，随「保存」落库，复制画布会带走）。选色时避开「节点选中=亮蓝 #1E88E5」与「连线=橙」即可。历史上试过品牌蓝（与选中同色，分不清）、深石板蓝 #2E4A62、砖红 #B4553C、墨绿 #2F6B5A，最终改为"默认值 + 每画布自定义"。栏目被选中或拖动时的描边用**白色**（橙描边在红底上看不见）。
- **样式可调（2026-10-21，画布级）**：工具栏「**⚙ 设置 ▾**」→「**样式**」，五组都可改：
  - **栏目头**：底色（20 色）、字色（12 个浅色）、字号（12–15）、字重（半粗 / 粗）；
  - **节点名称**：字号（10 / 11 / 11.5 / 12 / 13 / 14）、字重（常规 / 半粗 / 粗）、颜色；
  - **选中**：环色、环宽（1–4px）、底色（12 个浅色）；
  - **链路**：环色、环宽（1–3px）、底色（12 个浅色）；
  - **连线**：颜色。
  每个颜色行末尾都有一个**系统取色器**（虚框小方块），预设不够用时任选任意颜色。
  改完**立即预览**；存 `canvases.style`（JSON），点「**保存**」才写入并生成版本，**跟着复制画布一起带走**；面板底部「**恢复默认**」一键回到出厂值。
- **不挂内容型悬停提示（2026-10-21）**：节点名称（原来是「名称 + 出处 + 备注」）、标签胶囊、标签条 chip、类型块都**不再挂 `title`** —— 鼠标滑过乱弹很烦。全名/出处改在「⋯」编辑框里看；按钮类提示（📝 / 📎 / ⋯ / ✕ / 缩放）保留，那些是操作说明。
- **节点外观（2026-10-21 调整）**：**常态 = 白底 + 浅灰边**（原来默认就是蓝边，和"选中=蓝底"同色系，容易混）；**悬停 = 蓝边 + 浅阴影**（**不改底色**，底色只留给选中）；**选中 = 底色 + 一圈玫红描边 + 阴影**；**链路 = 浅玫红描边 + 极浅粉底**（两种模式同款，只差"其余节点是否置灰"）；**待确认 = 底部 2px 琥珀细条 + 橙字**。这三套颜色都能在「⚙ 设置 → 样式」里改。名称用**11.5px 半粗体、近黑色**（比标签的 8.5px 明显重一档，扫一眼先看到名字）；**最多两行**（原来单行省略，长名称看不全），再长才截断；**不挂悬停提示**（内容型 tooltip 已按要求全部去掉），看全名点节点上的「⋯」。
- **备注（默认折叠）**：节点有备注时，名称右侧出现 **📝**，点它**单独展开/收起**；备注默认**不占版面**。备注原文也在鼠标悬停提示里。
  - 工具栏「**显示备注（N）**」是**总开关**：勾选=**一次展开所有**有备注的节点（N=有备注的节点数），取消=**全部收起**。它是**独立的开关**（只有你点击才会变，不会自己跳）；**默认不勾选**。勾选状态下，你新写的备注会**立刻展开**。
  - 单个节点的 📝 仍能**单独开关**，与总开关互不干扰；总开关**不给文字提示**（一按就看见节点展开/收起，再弹一行提示反而把画布挤一下）。
- **标签（常显，字段名 `tags`）**：常显在**名称下一行**（与名称行之间一条虚线），**不挤压名称**；**全量展示**（超宽自动换行），**点某个取值 = 按此标签筛选画布**（见下方「标签筛选」）。标记不参与连线。
  - **展示形态：每个类型一块**（2026-10-22 定稿，唯一口径）——每块**第一行是类型名**（**7.5px 小字**、类型色、不加粗，一眼看出这排胶囊属于哪类）+ 左侧一条 **2px 类型色竖条**表示归属；第二行起是该类型的全部取值，每个取值是**圆角胶囊**（8.5px、内边距 3px、间距 2px、浅底 + 同色字 + 同色细边，**常规字重不加粗**）。未分类**单独一块、灰竖条 + 灰「未分类」+ 灰胶囊**（画布**一个类型都没建**时不显示「未分类」这行字，只留灰胶囊）。块与块之间一条虚线。类型名仍是**纯展示**（不挂 tooltip、不可点；按类型筛走顶栏「🏷 标签」的组头）。
    ```
    研发组                        ⋯ 📎
    ┊ 类别                                ← 类型名（7.5px，蓝）
    ┊ (核心) (实验)
    ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
    ┊ 阶段                                ← 类型名（7.5px，绿）
    ┊ (进行中) (已验收)
    ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
    ┊ 未分类                               ← 灰
    ┊ (待补充)
    ```
    这样标签不会混成一排，且"谁属于哪一类"一眼能看出来（同类型共用一种颜色，未分类是灰的）。**点顶栏类型名 = 按类型筛，点节点上的取值 = 按标签筛**。
  - **标签类型（2026-10-21，维度分色）**：标签可以归入**类型**（如「类别」「阶段」），每类一种颜色 —— 节点上按**类型顺序分块**，每块首行是**小号类型名**、左侧一条 2px 类型色竖条，取值是**圆角胶囊**（浅底 + 同色字 + 同色细边、常规字重）；**没归类的叫「未分类」**，灰竖条 + 灰胶囊（与任何彩色类型都不撞）。
  - **同一个词可以同时属于多个类型**（2026-10-26）：在各类型的输入框里各写一次即可，两个都算数（以前会"搬走"—— 写进 B 类型，A 类型下就没了）。节点上因此可能出现**两个同名但不同色的 chip**，标签条里也是**两个同名 chip、各算各的节点数**；点哪一个都只亮**该类型下**带它的节点。归属是**节点级**的：同一个词在 A 节点挂「类别」、在 B 节点挂「阶段」互不影响。
  - **管理类型**：工具栏「**⚙ 设置 ▾**」→「**标签类型**」→ 新建 / **改名（点 ✎ 或直接点类型名；已归到该类型的标签会跟着改）** / 改色（20 色预设 + 系统取色器）/ 上下移（决定节点上分行与标签条里的先后）/ 删除。**删除类型只取消归属、不删节点上的标签**（标签回落「未分类」），且可 `Ctrl+Z` 撤销。类型改动与标签一样是**草稿**，点「保存」才写入版本。
  - **打标签**：节点「⋯」编辑框里**每个类型一个多行框**（自适应高度，框下「已有：」候选胶囊可点击加入/移出），在该框里首次出现的新词**自动归到该类型**；**同一个词写进多个类型的框 = 同时属于这几个类型**（各算各的，互不搬运；节点上会显示成多个同名不同色的 chip）；写进「未分类」框 = 不带类型（两处都写时以类型为准）。归属是**节点级**的（存 `nodes.tagtypes`），所以同一个词在 A 节点挂「类别」、在 B 节点挂「阶段」互不影响。
  - 一个标签在**一张画布内只属于一个类型**；`nodes.tags` 的存储格式**没变**（仍是逗号串），类型只存"归属"，所以老画布打开即可用、无需迁移。
- **同栏分组（虚线框）**：选中**同一栏**的若干个节点（`Ctrl`/框选多选）→ 右键 →「**设为分组**」→ 填组名（可从本栏已有组名里选）→ 这些节点会被**虚线框**圈住、**并自动归拢成连续一段**（框内不会有别的节点）。「取消分组」把选中节点移出组；某组只剩 1 个成员时**整组自动散开**。
  - **整组拖动（2026-10-21）**：编辑模式下**拖分组名（虚线框上那个小标签）**＝把这**一整组**在本栏内换位置，组内成员**连续地**插到目标处，**不会把别的组劈开**（拖到另一个组上＝放到那一组**之后**）。跨栏拖动不支持（提示「分组只能在本栏内移动」）。
  - 分组是**纯视觉**：不改节点 id、**不参与连线**（连线仍按节点本身算），也不影响导出。
- **流程图（节点级按钮）**：编辑模式下每个节点名称右侧有 **📎 上传 / 🖼 替换** 按钮——**直接点即可选图上传或替换**；节点**下方显示缩略图**，**点击缩略图看大图**，缩略图右上 **✕** 删除流程图。
- **栏目可增删/排序**：工具栏「**＋ 栏目**」新增栏目；栏目头右侧 **✕** 删除（含其下节点，**一次确认**）；**拖动栏目头**调整栏目顺序。
- **拖动排序 / 跨栏**：编辑模式下直接**拖节点**——拖到同栏另一个节点的位置 = 换序；拖到**别的栏** = 把节点移过去。（**锁定画布**时拖动停用。）
- **重复检测**：新增/改名时会检查**同列同名**（忽略首尾空格与大小写），有重复则拦下并提示已有的那个。
- **明确 / 待确认**：
  - **节点**：新增默认「明确」；标为待确认 = 右键 →「标记待确认」（或选中后按 **`T`**，再按一次变回明确）。**`T` 支持多选**：选中的节点若**全都**是「待确认」则一起转「明确」，否则一律转「待确认」。待确认节点显示为**底部 2px 琥珀色细条（#D08A2E）+ 名称旁橙字「待确认」**（原来用橙色虚线框，会和选中/链路的彩色环叠在同一根边框上，谁都看不清）；**默认显示**，取消勾选顶部「显示待确认」才隐藏。
  - **连线**：右键连线（或「该节点连线（N）」条上的状态按钮，或**选中连线后按 `T`**）→「标记待确认」；`T` 也支持多选连线。待确认连线显示为**橙色虚线**，**默认显示**（同上，取消勾选即隐藏）。
  - 顶部「显示待确认」徽标同时给出**节点数与连线数**。
- **连线 / 取消（同一操作，开关式）**：选中节点 → 按 **`L`**（或右键 →「从此节点连线」）→ 进入**连线模式**：
  - 点某个目标节点 = **连线**；**再点同一个目标 = 取消连线**（反复点即反复切换，可一次连多个）；
  - 结束连线模式：`Esc` / 点空白 / 再点一次起点 / 再按一次 `L`；
  - **同一栏目内的两个节点不能相连**（避免误连）——点同栏的目标会提示并拒绝。
- **删除连线（不弹确认框）**：
  1. **连线模式下再点一次目标节点**（最顺手）；
  2. **选中任一节点** → 上方出现「**该节点连线（N）**」条，列出它的所有连线，每条带状态与 **✕** —— 直接点 ✕ 删除（连线密集时在画布上不好点，这里最直接）。这条**受工具栏「🔗 连线」开关控制，默认关**（开关状态存在本机）：关着时选中节点不会再自动铺出连线；
  3. **点连线选中**（选中线变**深橙红加粗**）→ 按 **Delete / Backspace** 删除；
  4. **右键连线** →「删除连线」。
- **框选 / 批量删除**（编辑模式）：在**画布空白处按住拖动**画出矩形选框，**碰到就选中**（节点按外框相交、连线沿路径采样命中）；松开后按 **Delete / Backspace** 一次性删除。
  - 只选中连线时**直接删**；只要框里有节点，删除前**弹一次确认**（列出将删除的节点数/连线数）。
  - **Shift / Ctrl + 点击**节点或连线 = 加选（改为多选，可逐个累加）。
- **快捷键总表**：`Enter`=改名（节点；或**选中的栏目**） · `L`=从此节点连线/结束连线（选中单个节点） · `↑`/`↓`=在**同栏目内**上下移动选中（按渲染顺序，到列头/列尾就停） · `←`/`→`=跳到**相邻栏目**（取纵向中心最近的节点；空栏目会跳过、继续往同方向找） · 两者都会在选中项移出视口时**自动平移带回来** · `Delete`/`Backspace`=删除选中（节点/连线/栏目） · **`Ctrl+↑`/`Ctrl+↓`=把选中节点在本栏内上/下挪一位**（多选则整块相对顺序不变地移动；跨到别的组会**自动脱离该组**，不会把组劈开） · **`M`=备注 / 标签**（选中单个节点时打开那个小编辑框） · **`N`=新增节点**（插在选中节点之后；没选节点但有选中栏目则加到该栏末尾） · **`Ctrl+E`=切换编辑模式**（与工具栏按钮等价） · `T`=标记待确认/明确（节点与连线，均可多选批量） · `Ctrl+S`=保存 · `Ctrl+Z`=撤销 · `Ctrl+Y`（`Ctrl+Shift+Z`）=重做 · `Esc`=取消编辑/结束连线 · 空格+拖动=平移。**焦点在输入框内或弹窗打开时不触发**；**画布锁定时编辑类快捷键不触发**（提示先解锁）。
- **点节点高亮链路**（**按栏目顺序定上下游**：左=上游、右=下游，**忽略连线箭头方向**；高亮 = 上游可达 ∪ 下游可达）：
  - **单个节点**：既往左也往右。例：点「管理后台」（交付物）→ 往左亮出产出它的「研发组 / 前端开发 / 后端开发」，往右亮出它依赖的外部服务；点「研发组」（团队）→ 往右铺开它支撑的能力与交付物；
  - **Ctrl / Shift / ⌘ + 点击多个节点 = 叠加筛选**：每多选一个点，就与它的高亮集合取**交集**，越选越少。例：先点「研发组」→ 再 Ctrl 点「前端开发」，交集只剩同时满足两者的节点，越选越少；**选中的点本身始终高亮**；
  - **链路与选中同一套视觉语言：白底 + 蓝色描边**，不用实心蓝底（会把节点里的标签和 📝/⋯ 按钮压得看不清），也不用浅蓝填充（**投屏时几乎看不见**）；
  - **主次靠色相深浅 + 描边粗细**：**选中 = 2px 玫红环（--sel #C2255C）+ 阴影（纯白底）**，**链路 = 1px 浅玫红环（--sel-lt #D76A8E）+ 极浅粉底 #FBEDF2**，其他 = 1px 浅灰边（以上都可改，见「样式」那条）；
  - **只差“其余节点是否置灰”**：查看模式**置灰**其余节点，便于专注看一条链路；编辑模式**不置灰**（要连线/改名，目标不能灰掉）。
- **标签筛选（成员资格高亮，2026-10-15）**：与「点节点高亮链路」是**两个维度**——链路高亮沿连线走上下游；标签筛选只看「**哪些节点带这个标签**」，有没有连线都亮。两者**互斥**（选节点即退出标签筛选）：
  - **入口一**：直接点节点上的**标签 chip**（就地筛，最快）；
  - **入口二**：工具栏「**🏷 标签**」展开**标签汇总条**（默认收起、零占位）：列出画布全量标签 + 节点数（`×N`），按**使用频次降序**；点 chip 筛选，当前筛选中的 chip 填充高亮；
  - **按类型筛（2026-10-21）**：标签条按**类型分组**（组头 = 类型色点 + 名称，末尾是「未分类」组）。**点类型名 = 亮出该类型下所有取值的节点**（例：点「类别」→ 带该类型任一取值的节点全亮）；**点「未分类」组头 = 亮出所有只带未分类标签的节点**；点单个取值仍只亮它。筛选生效时按钮显示 `🏷 类型：类别 ✕`。
  - **取消**：再点同一个标签 / 点画布空白 / `Esc`；筛选生效时即使标签条收起，按钮上也会显示 `🏷：某标签 ✕`（点它 = 清筛选并展开标签条），不会出现"画布灰了一片却不知道为什么"；
  - 标签条与节点 chip 的计数口径一致：**跟随「显示待确认」开关**（隐藏的待确认节点不计入、也不会被点亮）。

## 导出图片（PNG）

工具栏「**导出 ▾**」→「**导出图片（PNG）**」：把**整张画布**（所有栏目，含分组框、标签、连线）导成 PNG，**2 倍分辨率**、不受当前缩放影响，选中/置灰等临时状态不会带进图里。文件名形如「画布名_20261021-1930.png」，右下角带画布名 + 导出时间的水印。

- **为什么是 PNG 不是 JPG**：这类图是「纯色块 + 细线 + 9–11px 小字」，JPG 的压缩会在文字边缘和细线处压出噪点（放大看发毛、线条发虚）；PNG 无损、颜色数少反而压得更好，纯色区域也不会出现块状伪影。
- 实现是**用 Canvas 2D 按数据重画一遍**（不是截屏），所以零依赖、也不会把工具栏/选中态带进去；**节点上的流程图缩略图会一起画进去**（先等图片加载完，等比装进原来的框）；隐藏的「待确认」节点按「显示待确认」开关决定是否入图。
- 只读账号也能导出（不改数据）。

## 导出（图 → 链路表）

工具栏「**导出链路表**」→ 导出 CSV（可直接用 Excel 打开）：

- **一行 = 一条链路**；**表头 = 各栏目**（当前画布的栏目名）；每格 = 该栏目上的节点名（不含图片/备注/标记）。
  例：`研发组 , 前端开发 , 管理后台 , 云服务器`
- **只导出「从第一个栏目出发、按栏目顺序向右连出去」的链路**：
  - 起点必须是**第一个栏目**里的节点；
  - 必须**至少连出去一次**（连不上的不导）；
  - **孤儿节点**、**不是从第一个栏目连过来的节点**，都**不导出**；
  - **忽略连线画的箭头方向**，只按**栏目先后（左→右）**走（与"点节点高亮链路"同口径）；**同一栏目内的节点互不连线**，因此不会出现同栏跳转；
  - 有分叉拆成多行；链路过多（>5000）会截断并提示。

> 用法：**图用来讨论确认**（直观、能指、发现遗漏、看流程图）；**导出链路表用来交付/统计**。
