## 首次登录

首次启动自动建一个管理员：

| 用户名 | 初始密码 |
|---|---|
| `admin` | `ES9kxuDLUyNfyzEfQtTEWhnNKM` |

> 这个密码**写在源码里**，公开仓库人人可见 —— 所以它是"入场券"不是长期密码：
> 用它登录后会被**强制改密**，改完才放行任何操作。

## 三种角色

| 角色 | 能做什么 |
|---|---|
| `admin` 管理员 | 管用户 + 能改画布 |
| `rw` 可编辑 | 能改画布 |
| `ro` 只读 | 只能看；**服务端**拒一切写请求，前端也收起编辑入口 |

只读账号也能**导出**（导出不写数据）。

## 管理用户（仅管理员）

右上角「操作人 ▾」→「用户管理」，或顶栏的「用户管理」按钮。

- **新增**：填用户名、选角色。**不填密码**时随机生成 26 位，**只显示这一次**（转告本人，他首次登录也会被要求改密）
- **改角色**：下拉即时生效——对方**下一次请求**就被按新角色处理，不用重登
- **重置密码**：同样生成随机口令，回显一次
- **删除**：点两次确认（4 秒内再点一次）；**不能删自己**，也**不能删或降级最后一个管理员**

## 改自己的密码

右上角「操作人 ▾」→「修改我的密码」，需要输入当前密码；新密码至少 6 位。

## 退出 / 切换账号

右上角「操作人 ▾」→「退出登录」：清掉本机令牌，回到登录框。换人、换角色都走这里。
> 只清**登录态**，不动未保存的草稿（草稿还在本机浏览器里，下次同一台电脑打开这张画布会再问一次要不要恢复）。

## 忘了管理员密码

```bash
ADMIN_PASSWORD=新的管理员密码 node server.js   # 启动一次即重置 admin 密码
```

之后正常启动即可。**每次带这个变量启动都会重置一次**，用完记得不带它。

## 与权限相关的行为

- **降权 / 删人立即生效**：令牌里只有用户 id，服务端每次回库查角色
- **升级到 0.2.0 后旧令牌全部失效**（旧令牌没有用户 id），所有人需重新登录一次
- **登录限流**：15 分钟内失败 8 次 → 锁 15 分钟（`LOGIN_MAX` / `LOGIN_WINDOW_MIN` / `LOGIN_LOCK_MIN`）
- **图片** `/uploads/*` 也要登录（`<img>` 带不了鉴权头，走 `?t=<令牌>`）
- 密码在库里是 `scrypt` 加盐哈希，**不存明文**
