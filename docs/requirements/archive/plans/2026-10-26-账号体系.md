# 账号体系 Plan

> 归档样本（回填），与同名 spec 配对。交付日期 2026-10-26。

**Goal:** 用账号体系替掉"两个全局口令"，做到降权/删人立即生效，且不破坏既有画布与数据。

**方法概述:** 新增 `users` 表；密码 scrypt 加盐；令牌只装 `uid`、角色每请求回库查；`must_change` 强制首登改密；老口令保留在 `meta` 不再读（可回滚）。

**依赖:** Node 内置 `crypto.scryptSync`；已有鉴权中间件与登录门。

## 全局约束

- 零依赖、无构建
- 不动 `nodes/edges/columns/tag_*` 任何表结构与数据
- 所有权限判定在服务端；前端隐藏按钮不算权限
- 迁移幂等：重启多次结果一致

## 不做的事（YAGNI）

- 不做用户自助注册、邮件找回、密码复杂度策略
- 不做用户组 / 项目级权限
- 不做"改密踢下线"（需要令牌版本号，留作后续）
- 不迁移 `meta.password/ro_password`（保留便于回滚，但不再读取）
