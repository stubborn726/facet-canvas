# 变更记录

> 每次发布追加一节（新的在上）。格式：`## [版本] — YYYY-MM-DD`，正文分 **新增 / 变更 / 修复 / 兼容 / 移除**。
> 版本号见 `package.json`。

## [0.2.0] — 2026-10-26

### 新增
- **账号体系**：管理员 / 可编辑 / 只读三种角色；管理员可新增用户、改角色、重置密码、删除；用户可改自己的密码；首次登录**强制改密**。
- **`verify.js` 数据体检**：只读输出 integrity + 各表内容指纹 + 卫生检查；`--save` / `--baseline` 做前后比对（有差异退出码 1，可进 CI）。
- **示例数据升级**：5 栏 / 33 节点 / 69 连线，含 4 类标签（12 个标签）、3 个同栏分组、3 条「待确认」连线、2 条备注——首屏就能看出能力。
- **`AGENTS.md` + `docs/` 文档体系**：给任何 AI agent（以及未来的自己）一份可执行的工作指南。
- **CI**：Node 22 / 24 跑 `npm test`。
- **`SECURITY.md`**：写清威胁模型——默认管理员口令公开（用 `ADMIN_PASSWORD` 首启初始化）、数据库明文、令牌 365 天且改密不踢设备。
- **`.gitattributes`**（统一 LF）与 `.github/ISSUE_TEMPLATE`。
- `docs/designs/` 两篇决策记录；`AGENTS.md` 的「常见任务 → 改哪里」定位表。
- **文档一致性断言**：`npm test` 先跑 `test/docs-consistency.js` —— 校验默认口令在多篇文档与 `server.js` 常量之间一致、`package.json` 版本号与 CHANGELOG 首条一致、所有 md 的相对链接可达（这三类是最容易漂移的）。

### 变更
- 登录改为「**用户名 + 密码**」；顶栏「操作人」变成账号菜单（改密 / 用户管理 / 退出）。
- README 重构为门面（400+ 行 → ~130 行），操作与实现细节拆到 `docs/`。
- **文档体系收敛**：目录树只保留 README 一份（AGENTS 改为「新文件放哪」表，DEPLOY 改为「部署集清单」）；`docs/README.md` 增篇目索引；新增 `CONTRIBUTING.md`；`designs/` 每篇加状态头；AGENTS 去掉会过期的近似行数。
- 前端拆成 `index.html` + `app.js` + `style.css`（仍是原生、无构建）。

### 兼容
- `nodes` 新增 `tagtypes` 列：**只加列、旧行不动**；老版本快照 / 老本地草稿按自带 `tagDefs` 展开。
- 升级到 0.2.0 后**旧登录令牌一律失效**（令牌里没有用户 id），所有人需重新登录一次——这是有意的。
- **浏览器本地存储键改名**：`aec_*` → `fc_*`（含未保存草稿）。已内置一次性迁移，**升级不会丢草稿**。
- **备份目录前缀改名**：`aec-<时间戳>` → `facet-<时间戳>`。**早期前缀的备份目录不再参与自动轮转**（保留不删，需要时手动清理）。

### 移除
- 两个全局口令（`APP_PASSWORD` / `READONLY_PASSWORD`）及其写死在源码里的默认值。
